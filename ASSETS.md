The Herencia title is **Empanadas Herencia** without a demo suffix, as requested. Its current screenshot and project note still accurately reflect simulated orders and disabled payments until live operation is verified.

The laptop and phone frames are original CSS compositions for this portfolio: straight black chassis, restrained borders and generic cameras; no Apple, ASUS or other device branding/artwork is used.

`public/icons` preserves the original MUI Email, LinkedIn, GitHub and AttachFile paths, plus matching control icons extracted from **@mui/icons-material 5.11.16**. This allows the original appearance and hover glow without loading the old MUI/Emotion runtime. The original MIT license is included in `public/icons/LICENSE.txt`. Brand marks retain their respective owners; no affiliation is claimed.

Technology logos and experiment imagery/code were already supplied in this repository. Experiment originals are preserved; the runtime preparation step wraps them for bounded, same-page play/pause/reset. Review any new experiment's source, license, assets and external connections before adding it to the public catalog.
