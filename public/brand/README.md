# Alejandro Agredo — approved logo

Approved November 18, 2026: refined A/arrow, **Original Electric Blue** (comparison 01). The website header uses the grayscale symbol alone, without a name beside it. The favicon uses a dedicated bolder black-to-gray version. Blue, white and black remain reusable brand masters. The symbol/wordmark SVGs have transparent backgrounds and outlined wordmark lettering.

| File | Use |
| --- | --- |
| `alejandro-symbol-grayscale.svg` | Grayscale symbol used by the website header |
| `favicon-bold.svg` / `favicon-bold.ico` | Current browser icon: heavier black-to-gray A on a soft light tile, visible on light and dark tab bars |
| `alejandro-symbol-blue.svg` | Blue symbol for business cards and other brand materials |
| `alejandro-wordmark-blue.svg` | Blue symbol with white name for other dark surfaces |
| `alejandro-symbol-white.svg` / `alejandro-wordmark-white.svg` | Single-color light version for dark surfaces |
| `alejandro-symbol-black.svg` / `alejandro-wordmark-black.svg` | Single-color dark version for light surfaces |
| `favicon-electric-blue.ico` | 16, 32 and 48px browser fallback, generated from the blue symbol |
| `apple-touch-icon.png` | 180px home-screen icon with the portfolio's #333 background |
| `favicon-grayscale.ico` / `apple-touch-icon-grayscale.png` | Previous gray favicon and current Apple home-screen icon |

All three color variants share the same geometry. Use the symbol alone at small sizes; 24px or larger is preferred for ordinary interface use. Browser icons also include the required 16px size. Preserve proportions and the negative space between the three facets.

The selected blue gradients use four stops (0%, 30%, 67%, 100%), from top to bottom:

- Left facet: `#F0FAFF`, `#5CD5FF`, `#008CFF`, `#0035FF`.
- Right facet: `#0068FF`, `#0041FF`, `#0924F5`, `#1600D8`.
- Inner facet: `#23B7FF`, `#087AFF`, `#0745FF`, `#1000E6`.
- Wordmark white: `#F4F5F7`; monochrome dark: `#17191D`.

The SVG files are the editable vector masters. No external fonts, linked images, scripts or paid service are required to use them.

The dedicated favicon preserves the A paths with an 8-unit same-color stroke for small-size weight. Its three diagonal gradients run from near-black (#050505 / #0B0B0B / #111111) to gray (#454545 / #767676 / #555555). The #F2F2F2 rounded tile keeps the dark mark readable in dark browser chrome. It does not replace the header logo or the reusable brand masters. The ICO contains 16, 32 and 48px renders of this SVG; `public/favicon.ico` carries identical bytes for older direct requests.
